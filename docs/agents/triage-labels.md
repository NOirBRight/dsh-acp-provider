# Triage Labels

The engineering skills use five canonical triage roles. This table maps each role to this repository's GitHub label.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is required |
| `needs-info` | `needs-info` | More information is required from the reporter |
| `ready-for-agent` | `ready-for-agent` | The issue is fully specified for an autonomous agent |
| `ready-for-human` | `ready-for-human` | Human implementation is required |
| `wontfix` | `wontfix` | The issue will not be actioned |

When a skill names a canonical role, apply the corresponding GitHub label from this table.
